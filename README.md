# Atividades de Java - Etec Pedro Ferreira Alves
Aqui estão todos os exercícios de Java que fiz.
## Exercícios incluídos:
### 1. CRUD de Alunos e Professores (Atividade Final)
- Aplicação completa com telas em **JavaFX + FXML**
- Cadastro, edição, exclusão e listagem de Alunos e Professores
- Conectado com banco MySQL
- Usa padrão DAO
### 2. Testes Unitários
- Classe Calculadora simples
- Testes feitos com JUnit 5
### 3. Calculadora Financeira
- Calcula desconto, juros simples, média de valores e verifica se o aluno foi aprovado
- Tem tratamento de erros (exceções)
- Vários testes unitários
### 4. Aula de Calculadora Básica
- Exercício inicial só de soma
## Tecnologias usadas
- Java 17
- JavaFX + FXML
- Maven
- MySQL + JDBC
- JUnit 5
## Como rodar o CRUD (principal)
1. Crie o banco no MySQL:
CREATE DATABASE escola CHARACTER SET utf8mb4;

Edite o arquivo config.properties e coloque seu usuário e senha.
Na pasta do projeto, rode o comando: mvn clean javafx:run
